# SkillBridge SA

**Tagline:** Turn your skills into your next opportunity.

SkillBridge SA is a South African youth employment and work-readiness platform designed to connect education, skills, experience and projects with relevant career pathways, opportunities and practical experience.

## Technology Stack

- Backend: Python + FastAPI
- Frontend: React + Vite
- Database: MySQL
- Authentication: JWT
- API: REST
- Development: VS Code

## Core User Roles

- Candidate
- Employer
- Administrator

## MVP Flow

Profile → Skills → Matching → Opportunities → Applications

## Project Structure

- `backend/` — Python FastAPI backend
- `frontend/` — React frontend
- `database/` — SQL schema and seed data
- `docs/` — project documentation
- `screenshots/` — competition/demo screenshots
